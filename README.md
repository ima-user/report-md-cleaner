# Report Markdown Cleaner
A cleaning tool designed specifically for industry research report Markdown files, automatically resolving OCR noise, unexpected line breaks, and broken tables.
## Problems Solved (Features)
- **Formatting Restoration**: Fixes intra-paragraph hard wraps caused by OCR and repairs corrupted Markdown tables.
- **Image & Link Cleaning**: Cleans up broken references and normalizes local or remote image paths.
